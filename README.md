# OSS Digital Catalog — Vercel-ready starter

This is the first static version of the ONE STOP SOLUTION (OSS) catalog.

- 37 product listings
- ₹500 Minimum Order Quantity (MOQ)
- Search and category filters
- Stock filters
- Single-product WhatsApp enquiry
- Multiple-product enquiry using +
- OSS branding
- Premium HD Enterprise-inspired visual feel
- Red zoom in/out hero animation

## Deploy to Vercel
Upload the ZIP/project to Vercel. No Firebase is connected yet. Firebase + GitHub will be added in the next step.

## Important
The visible product image set available in the current workspace contains 36 product photos plus branding assets. OSS_015 has a temporary placeholder until its exact product photo is supplied. This can be replaced later without changing the product code.
